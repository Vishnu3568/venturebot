# VentureBot

VentureBot is a controlled autonomous experimentation system that starts with **₹1,000 of capital** and systematically searches for legitimate, repeatable revenue opportunities.

## What It Is

VentureBot treats revenue generation as a scientific process:
- Opportunities are identified through research
- Each opportunity is scoped as a controlled experiment
- Capital is allocated only based on measurable evidence
- Results are measured, analyzed, and used to improve future experiments

## How It's Being Built

This project is being developed **incrementally, one verified step at a time**. Nothing is added to the codebase until it has been reviewed and approved.

**Current version: V0 — Foundation**

## Important Constraints

- **No autonomous spending** — all financial actions require explicit human approval
- **Capital is never fully deployed** — a reserve is always maintained
- **Evidence-first** — no capital is spent without data supporting the decision
