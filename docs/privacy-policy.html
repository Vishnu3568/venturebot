Privacy Policy

This Privacy Policy explains how the VentureBot project collects, uses, and safeguards data during its autonomous experimentation and problem-validation pilots.

Effective Date: October 10, 2026 Project: VentureBot Meta App ID: 1063651013045060

1. About VentureBot

VentureBot is an open-source, evidence-driven autonomous opportunity-discovery and experimentation platform. VentureBot tests hypotheses about business problems and informational demand using bounded, transparent pilots with strict capital and privacy guardrails.

The current active experiment is the Solopreneur Financial Workflow Guide Problem Validation Pilot (Experiment ID: 49fde874-9387-5056-934c-51a9cfca164f).

2. Information Collection & Principles

VentureBot operates under a strict zero personal data collection policy for its public pilots:

What We Do NOT Collect
  • No Personal Identifiable Information (PII): We do not collect names, email addresses, phone numbers, postal addresses, or job titles.
  • No Financial or Payment Data: The workflow guide is completely free. We never request credit card numbers, bank accounts, UPI IDs, or billing addresses.
  • No User Accounts or Logins: There are no registration forms, passwords, user profiles, or social logins.
  • No Tracking Cookies: We do not set or read any cookies on your device.
  • No Device Fingerprinting: We do not collect device fingerprints, canvas hashes, battery state, or persistent identifiers.

3. Telemetry & Measurement Data

To measure whether visitors find the financial workflow topic relevant, the guide page (guide.html) triggers a single, lightweight server-observed beacon event upon loading.

What the Telemetry Beacon Transmits:

  • The public experiment identifier: experiment_id: "49fde874-9387-5056-934c-51a9cfca164f"
  • The event type identifier: event_type: "guide_access"

How Telemetry Is Processed on the Server:

The beacon request is received by a stateless edge worker (Cloudflare Workers). The worker verifies the experiment identifier and increments an aggregate numeric counter in a SQL database table (Cloudflare D1). The record consists strictly of:

  • experiment_id: The experiment UUID string
  • event_type: The literal string guide_access
  • date_bucket: The current UTC calendar date (e.g., YYYY-MM-DD)
  • access_count: An integer counter incremented by 1 per event
IP Address & Header Handling

Client IP addresses and User-Agent strings are NOT logged, stored, or persisted in our telemetry database. The edge worker does not associate access events with individuals, IP addresses, or network identities.

4. Use of Telemetry Data

The aggregate daily access counts are used exclusively by the VentureBot experiment evaluation engine to determine macro audience interest in the problem space. Aggregate counts are compared against aggregate Meta link-click reports to inform experiment decision milestones (Kill, Iterate, Scale, or Hold).

Telemetry data is never used for behavioral targeting, audience profiling, cross-site tracking, ad remarketing, or sale to third parties.

5. Cookies & Third-Party Tracking Scripts

Our public pilot pages contain zero third-party tracking or analytics scripts:

  • No Google Analytics: No Google Analytics or Google Tag Manager scripts are embedded.
  • No Meta Pixel: No Meta / Facebook Pixel tracking tags or conversion scripts are embedded on our pages.
  • No Session Recording: No third-party session recording or heatmapping tools (e.g., Hotjar, FullStory) are used.

6. Third-Party Infrastructure Services

The VentureBot pilot utilizes the following third-party infrastructure providers to deliver content and process aggregate counts:

  • GitHub Pages (GitHub, Inc. / Microsoft): Hosts the static HTML, CSS, and image files for this website. When you request a page, GitHub's infrastructure processes standard HTTP connection requests. For more details, refer to the GitHub Privacy Statement.
  • Cloudflare Workers & D1 (Cloudflare, Inc.): Provides stateless edge compute for receiving the non-blocking guide-access beacon and maintaining aggregate daily counts. For more details, refer to the Cloudflare Privacy Policy.
  • Meta Platforms, Inc.: VentureBot uses Meta Marketing APIs to deliver educational ads that link users to this pilot page. Ads are managed under Meta Developer App ID 1063651013045060 (currently in Development Mode). VentureBot does not access personal profile data or private user data from Meta.

7. Data Retention & Deletion

Because VentureBot does not collect personal data, individual user profiles, IP addresses, or identifiable records, there are no individual personal records stored that could be exported or deleted upon request.

Aggregate numeric daily access counts are stored in the project's telemetry database for the duration of the experiment lifecycle to support auditable, reproducible research reporting.

8. Meta Developer Platform Context

This Privacy Policy is published in connection with the VentureBot Meta Developer Application (App ID: 1063651013045060).

The application is utilized exclusively by the project operator via backend server-to-server API integrations to manage advertising campaigns for VentureBot problem-validation experiments. The application does not offer Facebook Login, does not collect user data from social profiles, and does not provide public consumer-facing API endpoints.
